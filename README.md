# Next Health - Landing Page Responsiva

Landing page responsiva para **Next Health**, startup especializada em gestão inteligente de plantões para equipes de enfermagem. Desenvolvida com **HTML5**, **CSS3** e **JavaScript puro**, a página apresenta:

- Design moderno e adaptável (mobile, tablet, desktop)
- Formulário funcional integrado ao **EmailJS** para captação de leads
- Destaques do produto: solução para escalas automatizadas, compliance com normas e dashboard intuitivo

## Tecnologias

**Frontend**: HTML semântico, CSS Grid/Flexbox, media queries

**Funcionalidades**: formulário para contato usando a lib **EmailJS**, carrossel de equipe, menu mobile
